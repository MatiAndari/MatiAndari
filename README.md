### Sobre mí

Construyo productos web de punta a punta: desde el diseño y el frontend hasta el backend, la base de datos y el deploy.
Con **vm_webs** ayudo a negocios a vender y operar online con sitios rápidos, tiendas conectadas a medios de pago y bots que automatizan la atención y la gestión.

- **Web:** landings, sitios institucionales y catálogos con Next.js
- **E-commerce:** carritos, integración con Mercado Pago y pedidos por WhatsApp
- **Automatización:** bots de Discord y WhatsApp, CRMs y paneles de administración a medida
